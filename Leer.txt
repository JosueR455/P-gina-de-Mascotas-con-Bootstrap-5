El para ejecutar el programa favor seguir los siguientes pasos:

1-En la carpeta donde se manejará todo el proyecto crear una carpeta llamada "styles" y otra llamada "images"
2-Dentro de images copiar las imagenes.
3-Dentro de styles copiar el archivo "stylesBoostrap.css"
4-Finalmente copiar el archivo "indexBoostrap.html" en la carpeta principal junto a las otras carpetas creads.
De esta manera ya se podrán ver la pagina web en el navegador con las imagenes y funciones css correctamente.
